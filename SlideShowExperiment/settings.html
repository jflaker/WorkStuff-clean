Display Board Settings

Set the network folder and timings. You do not need to double every backslash yourself.

Type it the normal Windows way: two backslashes, then server, then folders.
Example: \\FILESERVER01\Slideshow\images

Windows path: —

Usually just images (next to these scripts). Not a network path.

About backslashes

In Windows you use \\server\share\folder. Inside a JSON file each \ must be written twice, so it looks like "\\\\server\\share\\folder". This page does that conversion for you when you Save or Download.

What you type hereWhat ends up in config.json
\\FILESERVER01\Slideshow\images "\\\\FILESERVER01\\Slideshow\\images"
//FILESERVER01/Slideshow/images (also OK) converted to the same JSON form
After saving
  1. Put config.json in the SlideShowExperiment folder on the display PC.
  2. On that PC run: .\Apply-Config.ps1 -TriggerSync
